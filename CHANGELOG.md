# Changelog

## v1.5.0

- Hid HTML5 ZIP import from the production UI.
- ZIP files are no longer advertised or accepted as an exportable source.
- Dragging/importing a ZIP now returns a clear message to use the official tag export instead.
- Supported production sources are SeenThis tags, Adform tags and Google Campaign Manager XLS/XLSX.
- Experimental ZIP parser code is retained internally for future research but is not reachable from the normal workflow.
